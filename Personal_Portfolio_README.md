# 🎨 Personal Portfolio — Customizable Website

A responsive, single-page portfolio demo built with **HTML, CSS, and vanilla JavaScript**. The main idea behind this project is **appearance customization**: visitors can switch between light and dark mode, choose different fonts, and change the website's color palette in real time.

The portfolio content is sample content used to demonstrate the interface and its interactions.

## ✨ Features

### Appearance customization
- **Theme switching:** toggle between light and dark mode.
- **Color customization:** select a color palette from the settings panel and see the changes immediately.
- **Font customization:** switch between available font families.
- **Saved preferences:** theme, font, and color choices are stored in `localStorage` and restored after a refresh.

### Other interactions
- Responsive single-page layout with section navigation.
- Active navigation highlighting while scrolling.
- Portfolio project filtering by category.
- Testimonials carousel with previous/next controls and indicators.
- Scroll-to-top button.

## 🛠️ Built With

## 🚀 Getting Started

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` with the **Live Server** extension, or open it in your browser.
4. Open the appearance settings panel to try the colors and fonts, and use the theme toggle to switch modes.

No installation or build step is required. An internet connection may be needed for externally hosted fonts, icons, and styles.
